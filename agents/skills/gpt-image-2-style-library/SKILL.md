# GPT-Image2 Style Library Skill

This skill helps agents choose GPT-Image2 visual styles, industrial prompt templates, categories, and scene tags.

## Installation

```bash
npx gpt-image-2-style-library
```

Or install globally:

```bash
npm install -g gpt-image-2-style-library
```

## Usage

Once installed, your agent (Claude Code, Codex, etc.) can automatically select from the style library's templates, styles, scenes, and pitfall rules to generate copyable GPT-Image2 prompts.

Example request: `Use the gpt-image-2-style-library skill to generate a city life system map`

## What's Included

- 13 categories (UI, Infographic, Poster, Product, Brand, Architecture, Photography, Illustration, Character, Scene, History, Document, Other)
- 19 visual styles (3D, Flat, Minimalist, etc.)
- 10 scenes (Creative, Tech, Social, Education, etc.)
- 22 industrial-grade prompt templates with guidance and pitfall warnings
